# 🌿 Nino — Cuidado emocional

## Sobre o projeto

O Nino é um projeto desenvolvido com a proposta de ajudar jovens estudantes a lidarem melhor com a ansiedade e com as dificuldades do dia a dia escolar, principalmente no ensino médio e no ensino superior.

A ideia é oferecer um espaço acolhedor, leve e interativo, no qual os usuários possam conhecer melhor suas emoções e encontrar maneiras de cuidar do próprio bem-estar.

## 🎯 Objetivo

O objetivo do Nino é incentivar o autoconhecimento e o equilíbrio emocional por meio de recursos que possam fazer parte da rotina dos estudantes. A plataforma reúne ferramentas de registro emocional, organização de pensamentos e momentos de tranquilidade, buscando tornar o cuidado com as emoções mais acessível.

## ✨ Funcionalidades

O projeto conta com diferentes recursos pensados para tornar essa experiência mais agradável:

- **Registro emocional:** permite registrar sentimentos, escrever anotações e consultar, editar ou excluir registros.
- **Calendário emocional:** organiza os registros por data e utiliza cores para facilitar a identificação das emoções.
- **Espaço de conforto:** oferece exercícios de respiração, sons ambientes e frases de acolhimento para momentos em que o usuário precisa desacelerar.
- **Mascotes:** permite escolher um personagem para acompanhar a experiência no aplicativo.
- **Mural de post-its:** espaço para escrever e organizar frases, lembretes e pensamentos.
- **Página de membros:** apresenta os integrantes do grupo e os mascotes relacionados a cada criador.

Além dessas funcionalidades, a proposta do Nino é reunir informações e recursos que ajudem os jovens a compreender melhor a ansiedade e a buscar apoio quando necessário. A plataforma não substitui o acompanhamento de profissionais de saúde.

## 🛠️ Tecnologias utilizadas

As principais tecnologias utilizadas no desenvolvimento foram:

- **Node.js:** execução do JavaScript no servidor.
- **Express:** criação do servidor e organização das rotas da aplicação.
- **EJS:** criação das páginas dinâmicas.
- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e adaptação visual.
- **JavaScript:** funcionalidades e interações da aplicação.
- **Bootstrap:** apoio na construção de uma interface responsiva.
- **Firebase:** armazenamento e integração dos dados na nuvem.

## 📁 Estrutura do projeto

O projeto utiliza uma organização baseada em rotas, páginas e arquivos estáticos, buscando manter o código separado e facilitar sua manutenção.

- `routes/`: arquivos responsáveis pelas rotas da aplicação.
- `views/`: páginas e layouts desenvolvidos com EJS.
- `public/`: arquivos estáticos, como CSS, JavaScript e imagens.
- `config/`: configurações utilizadas pelo projeto.

## ▶️ Como executar o projeto localmente

Para executar o Nino no computador, siga os passos abaixo:

1. Instale o [Node.js](https://nodejs.org/).
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Instale as dependências:

   ```bash
   npm install
   ```

5. Configure o Firebase com as credenciais necessárias para o projeto.
6. Inicie o servidor:

   ```bash
   npm start
   ```

7. Abra o navegador e acesse:

   `http://localhost:3000`

O projeto será executado localmente. Para que as funcionalidades que dependem do Firebase funcionem, é necessário configurar corretamente as credenciais e os serviços utilizados pela aplicação.

## 💚 Sobre a ideia do Nino

A rotina de estudos pode trazer muitas cobranças, preocupações e momentos difíceis. O Nino surgiu da ideia de criar um espaço em que os jovens possam parar um pouco, reconhecer o que estão sentindo e encontrar formas de cuidar de si mesmos.

Mais do que registrar emoções, queremos que o projeto incentive os estudantes a olharem para o próprio bem-estar com mais atenção e acolhimento.
